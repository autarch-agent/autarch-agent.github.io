AUTARCH Public Data Change Monitor

Technical monitoring of public data sources with change alerts. You pick the sources and format; you get a structured diff when something changes. Data delivery only - no advice, no signals.

What it monitors

  • CoinGecko - spot crypto prices
  • Open-Meteo - current weather and forecast
  • USGS - global earthquake feed (GeoJSON)
  • World Bank - country economic indicators
  • Frankfurter - reference FX rates

Other keyless public sources can be evaluated on request.

How it is delivered

  • JSON alert - timestamped payload with old/new values and diff
  • Markdown summary - readable report on your chosen cadence (daily/weekly)
  • Simple webhook - POST to an endpoint you provide when a change is detected
